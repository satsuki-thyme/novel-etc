魔法のキーワードについては何度も考えてきた。作品をボツにして新しく始めると魔法について考えることになる。そこまで届かないものがほとんどだったけど、それでも10回くらいは新たなキーワード体系について思案したはずだ。

# 詠唱の長さ

魔法は短いキーワードで発動する世界観を採用してきた。これは今回も変わらない。2点の理由がある。

- 個対個の戦闘については先に攻撃したほうが有利になりそうなので、詠唱は短くなる方向に開発されるはず。大魔法は別。
- 長い詠唱をするにしても魔法現象を定義するには短すぎると思われ、スイッチの役割をする発動句のほうが自然な気がする。

僕の世界観ではそういうことになっている。作品の面白さとすると長い詠唱のほうが格好いいと思うけども、ここは世界の理をかいま見て気分よくなる意味においてわがままを通したかった。

ただ、だからといって「あ」で発動してはあまりにもあまりなので3～7音くらいが相場だということにしている。短すぎるとスイッチの役割を負いきれないのだ（たぶん）。

# 職種？として

魔法使いと、剣士や戦士は明確に分かれたりしない。たぶん現実はそうなる。だから僕の作品でもそれを採用する。

スポーツではなく戦いとなった場合、近接戦なら剣やナイフを使うほうが簡単だ。そういう武装をしつつ距離を取って魔法を使うのだと思う。

安全を考えて距離を取るはずだけど、相手が武装していなければスキを突いて駆け寄り切りつけるのも有効そうだ。そうなるとある程度は武器が使えないと厳しくなるんじゃないだろうか。

あとは自分の得手不得手によって戦術が魔法使い寄りか、戦士寄りかになると思う。そういう混濁した状況が考えられる。

# 魔法の杖

基本的には、なしで考えている。僕にとっての魔法は漫画「BASTARD!! ―暗黒の破壊神―」が基本だからだ。この作品で魔法の杖は使われなかった。米を食って育った人にとって主食とは基本的に米であるように、杖なしで育った僕にとって魔法とは杖なしなのだった。

# 世界設定

これまで78作品がボツになってきた。制作を始めようとした形跡がかろうじて見て取れる、程度のものも含めてだけど、いちおうカウントされてきた。

そのなかで一貫して一つの世界設定を使い続けている。別途考えるのが面倒なのだ。それに僕なりに思い入れのある設定なので作品が流れたくらいで捨てたくないのだ。

だけど統一された魔法のキーワード体系がない。毎作でテキトーに考えている。どうにかしたい。魔法が統一されているほうが美しいし面倒がない。なにか「これだ」というものを作りたい。面倒だけど。こうやって思考ノートを書きはじめたからには仕方ない。

# 規則

基本的になしでいきたい。難しいことを言いだすと不自由になってしまい、格好いいキーワードを設定できない。

だけど例えば小規模な魔法なら接尾辞として「～レット」などとするのはありだ。火系の語幹を「ハイフ」とした場合、小規模な火系の魔法は「ハイフレット」だ。

# あれ？

それにしても、思えば今ある世界観では魔法はプログラムのようにいくらでも作ることができる。プログラム名が自由に決められるのだから魔法のキーワードも自由に決められる。それを今ここで固定的に決めるのはおかしい――あれ？

考え直す必要がある。魔法のキーワードを決めるんじゃなくて、魔法のキーワードの管理方法を考えないと。

# 管理ツール

管理するには情報管理ツールが有用だと思う。

例えば「[Obsidian](https://obsidian.md/)」。他の選択肢として「Notion」というのも考えられるけどNotionは流行廃りに影響される。サービスが終了すると困る。それに対してObsidianはMarkdownファイルを手元のパソコンで管理するからサービス終了を気にすることはない。

さっそくObsidianをインストールした。魔法に限定しないで世界観を管理する。そのなかでフォルダ「magic-keyword」を作った。ここに魔法のキーワードをファイル名にし、作品番号をタグで関連づけしようと思っている。

――それで半日かけて設定をした。そんなに時間のかかることじゃないはずなのに思いのほか時間が過ぎていた。ObsidianのデータはDropboxでクラウド同期している。他の端末からアクセスする予定はないけど。でもバックアップとして有用だ。
